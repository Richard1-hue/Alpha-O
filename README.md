# Alpha-O

An AI helper that answers questions, built step by step to learn GitHub.

## What it will do

- Read a question from a GitHub Issue
- Send it to an AI service
- Post the answer back as a comment

## Tech used

- GitHub Issues
- GitHub Actions (YAML workflows)
- Markdown
